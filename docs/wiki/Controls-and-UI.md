# Controls and UI

## Movement & Camera

| Input | Action |
| :--- | :--- |
| `W` / `A` / `S` / `D` | Move forward / left / backward / right |
| `Mouse` | Look around |
| `Space` | Jump, swim upward in water, or ascend while flying |
| `Left Ctrl` | Sprint |
| `F` | Toggle Flight mode |
| `F5` | Toggle First-Person / Third-Person camera |

## World & Combat Interaction

| Input | Action |
| :--- | :--- |
| `Left Click` (hold) | Mine / break targeted block |
| `Left Click` (tap) | Melee attack mobs or players |
| `Right Click` | Place block, interact with Chest / Storage Terminal / Crafting Table / Furnace / Cooking Pot / Power Machine / Bed, open held Backpack, apply Fertilizer to Farmland, use Bucket (scoop water or milk Cows), cast/hook Fishing Rod, shoot Bow, or feed Breeding Feeds to animals |
| `Right Click` (hold) | Eat food or drink Herbal Tea (~1.2s; release or switch hotbar slot to cancel) |
| `1` – `9` or `Mouse Wheel` | Select active hotbar slot |

## Inventory, Skills & Recipe Browser

| Input | Action |
| :--- | :--- |
| `E` | Open / close 2x2 inventory & crafting screen (also shows Armor slots and JEI-style recipe sidebar) |
| `B` | Open / close your portable **Backpack** (opens the backpack in your active hotbar slot or first backpack in inventory) |
| `K` | Open / close the **Skills & Milestones** menu (view levels 1–1000, perks, and milestone unlocks) |
| `Left Click` (in UI) | Pick up / place full item stack |
| `Right Click` (in UI) | Pick up half stack / place single item (or clear search bar in Storage Terminal / JEI) |
| `Shift + Left Click` | Quick-transfer stack between inventory, hotbar, chests, backpacks, storage terminals, or furnaces |
| `R` (hovering an item in UI) | Show crafting/smelting **Recipes** that produce that item |
| `U` (hovering an item in UI) | Show **Usages** for that item in recipes |

## Multiplayer & Menus

| Input | Action |
| :--- | :--- |
| `T` | Open chat & slash command bar (releases mouse cursor to interact with buttons) |
| `Mouse Wheel` (in Chat) | Scroll up/down through past messages (stores up to 30 past chat messages) |
| `Left Click` (in Chat) | Click interactive action buttons (e.g. `[Accept]`, `[Deny]`, `[Teleport]`) |
| `Tab` | Hold to view online player list, latency, and group prefixes/ranks |
| `Esc` | Close open inventory/UI or open Pause Menu (does not freeze game in multiplayer) |
| `Y` | Advance time of day by 3 hours (singleplayer / local testing) |

## Settings & Audio Configuration

Access **Settings** from the Title Screen or Pause Menu to configure graphics, audio, voice chat, and controls:

- **Audio Volume Sliders**:
  - `Master Volume` — Overall master audio output volume (0% – 100%).
  - `SFX Volume` — Block placement, breaking, bow firing, footsteps, and tool sounds.
  - `Music Volume` — Ambient soundtrack and contextual exploration music.
  - `Voice Volume` — Proximity voice chat incoming player volume.
  - `Creature Volume` — Volume for all animal and monster ambient calls and hurt sounds.
- **Proximity Voice Chat**:
  - Select your active **Microphone Input Device** from the dropdown menu.
  - Voice audio is spatialized in 3D using low-latency ADPCM compression.
- **Display & Interface**:
  - `UI Scale` — Adjust HUD and menu scaling (`0.75x`, `1.0x`, `1.25x`, `1.5x`).
  - `FOV Slider` — Field of view adjustment (60° – 110°).
  - `Render Distance` — Chunk view distance (4 – 16 chunks).
- **Controls & Keybinds**:
  - Fully rebindable keyboard keys supporting any keyboard key (numpad keys, punctuation, arrow/navigation keys, and function keys F1–F24).
