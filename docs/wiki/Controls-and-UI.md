# Controls and UI

## Movement & Camera

| Input | Action |
| :--- | :--- |
| `W` / `A` / `S` / `D` | Move forward / left / backward / right |
| `Mouse` | Look around |
| `Space` | Jump, swim upward in water, or ascend while flying |
| `Left Ctrl` | Sprint |
| `F` | Toggle Flight mode |
| `F5` | Toggle First-Person / Third-Person camera |

## World & Combat Interaction

| Input | Action |
| :--- | :--- |
| `Left Click` (hold) | Mine / break targeted block |
| `Left Click` (tap) | Melee attack mobs or players |
| `Right Click` | Place block, interact with Chest / Crafting Table / Furnace / Bed, eat food, use Bucket, shoot Bow, or feed Wheat to animals |
| `1` – `9` or `Mouse Wheel` | Select active hotbar slot |

## Inventory, Crafting & Recipe Browser

| Input | Action |
| :--- | :--- |
| `E` | Open / close 2x2 inventory & crafting screen (also shows Armor slots and JEI-style recipe sidebar) |
| `Left Click` (in UI) | Pick up / place full item stack |
| `Right Click` (in UI) | Pick up half stack / place single item |
| `Shift + Left Click` | Quick-transfer stack between inventory, hotbar, chests, or furnaces |
| `R` (hovering an item in UI) | Show crafting/smelting **Recipes** that produce that item |
| `U` (hovering an item in UI) | Show **Usages** for that item in recipes |

## Multiplayer & Menus

| Input | Action |
| :--- | :--- |
| `T` | Open chat & slash command bar |
| `Tab` | Hold to view online player list & ranks |
| `Esc` | Close open inventory/UI or open Pause Menu |
| `Y` | Advance time of day by 3 hours (singleplayer / local testing) |
